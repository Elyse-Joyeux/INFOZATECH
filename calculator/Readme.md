# Calculator Project

This project is a simple web-based calculator built with HTML, CSS, and JavaScript. It provides a clean and responsive calculator interface for performing basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

- Basic math operations
- Clear and delete buttons
- Decimal input support
- Real-time display for current and previous calculations
- Responsive layout for desktop and smaller screens

## Tech Stack

- HTML
- CSS
- JavaScript

## Purpose

The calculator is a beginner-friendly frontend project designed to practice DOM manipulation, event handling, and UI layout design.
