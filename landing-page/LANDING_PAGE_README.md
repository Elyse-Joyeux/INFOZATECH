# Umucyo AI — Landing Page

A responsive landing page for Umucyo AI, based on the existing Umucyo project.

## Included
- Hero section with clear value proposition
- Features/benefits focused on Socratic learning and reducing AI overreliance
- Three-step "How it works" section
- Strong call-to-action
- Responsive mobile navigation
- Existing Umucyo logo asset
- Existing Next.js/Tailwind stack preserved

## Run
```bash
npm install
npm run dev
```

Then open the local URL shown by Next.js.

## Main files changed
- `src/app/page.tsx`
- `src/components/site-header.tsx`
- `src/app/globals.css`
