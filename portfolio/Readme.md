# Portfolio Project

This project is a personal portfolio website built to showcase the creator’s background, skills, projects, and contact information. It is designed as a modern single-page website that presents a professional online identity in a clean and visually appealing layout.

## Features

- Hero section with introduction and profile image
- About section highlighting background and interests
- Skills and strengths overview
- Project showcase with featured work
- Contact section with social links and resume download
- Responsive design for different screen sizes

## Tech Stack

- HTML
- CSS
- JavaScript
- Font Awesome icons
- AOS animations

## Purpose

The portfolio serves as a digital CV and personal brand page, helping communicate experience, technical interests, and professional goals to potential employers, collaborators, or clients.
